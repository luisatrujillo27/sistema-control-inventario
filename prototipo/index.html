INFORMACIÓN GENERAL

Acerca del sistema

Conoce el propósito y los componentes del proyecto.

Proyecto académico

Sistema de control de inventario

Propuesta de aplicación web para apoyar el seguimiento de productos y existencias de un supermercado.

Objetivo

Facilitar la consulta y el control de las cantidades disponibles, identificando productos que necesitan reposición.

Tecnologías del proyecto

Python, Flask, HTML, CSS y JavaScript. El proyecto original incorpora el patrón de diseño Observer.

Patrón Observer

Permite notificar a observadores cuando cambia el inventario para clasificar el nivel de existencias y generar alertas.
